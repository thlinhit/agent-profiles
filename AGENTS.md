# Agent instructions

## Domain language

Read [CONTEXT.md](./CONTEXT.md) before changing code, tests or docs. It is the project glossary.

- Use its terms exactly in code, comments, commit messages and docs.
- Do not use the words listed under `_Avoid_`.
- If a concept has no term, say so and propose one instead of inventing a name. Do not add it to `CONTEXT.md` without asking.
- Keep `CONTEXT.md` a glossary: no implementation details, specs or decisions.
